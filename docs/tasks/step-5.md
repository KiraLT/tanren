## Team charter: mcp-oauth
Mission: Claude Code attaches to `http://localhost:8787/mcp` **without a token**, is sent through the browser flow (login page → console magic link → consent) and comes back with a grant whose `tanren:read`/`tanren:write` scopes decide whether four or seven tools are listed; the three write tools (`write_plan_week`, `log_session`, `update_profile`) write through the `@tanren/db` repositories with the validation and idempotency rules of oauth.md §5; the dev bearer token keeps working locally as a fallback; the production config (`env.production` block, `MCP_RESOURCE_URL`, KV binding) is ready for the owner's runbook. No Durable Object. Agents never deploy.

## Decisions
- D1 Combined `OAuthProvider` (authorization server + resource in the one `tanren` Worker), KV-backed, no DO; the split v1 API is not used — accepted (Lead delegation); ADR-0011 records it. Facts: oauth.md §1 [V][S].
- D2 Authorization server on the `BETTER_AUTH_URL` host (`api.tanren.me`), resource on `mcp.tanren.me`; endpoints as full URLs; fallback = cross-subdomain cookie (oauth.md §1 VERIFY) — accepted (Lead delegation).
- D3 Identity: the grant's encrypted `props = { userId, scopes }` decoded with the shared `OAuthProps` schema; `McpAuth` returns an `McpPrincipal`; write tools are registered only for `tanren:write` — accepted (Lead delegation).
- D4 Login = Better Auth magic link reused server-side from the authorize page (`callbackURL` = the `/authorize?…` URL); consent = the provider's v1 consent helpers (no hand-rolled CSRF) — accepted (Lead delegation).
- D5 Write-tool semantics: `write_plan_week` = active plan only, week replace with session ids stable by `order`, sets replaced; `log_session` = create or replace by `sessionId`, duplicate `startedAt` refused; `update_profile` = merge or create (timezone required) — accepted (Lead delegation); oauth.md §5.
- D6 Dev bearer token stays as the local fallback (`McpAuth.layerLive`), so existing Claude Code setups and workerd tests keep working — accepted (Lead delegation).
