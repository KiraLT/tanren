## 1. Stability (verified `[T] src/index.ts`, per-module JSDoc, `[MIG]` "Unstable Module System")

Rule: `@stability unstable` means "breaking changes allowed in minors". `experimental` means "across patches". `stable` follows strict semver.

| Module | Import | Stability |

Core constructors/parsers (Struct, Class, TaggedError, brand, Literal(s), Union, optional(Key), Option*, DateTimeUtc*, Int, checks, decode*/encode*) are `@stability stable`. Per-export exceptions in `Schema.ts`: 132 `unstable` (network/host schemas: ByteSize*, Ip*/Mac*/Inet*/Unix*/Socket*, Graph, Cookie(s), Headers, UrlParams ...) and 46 `experimental` (DomainName, Host*, Port, DnsRecordType ...). | Unstable top-level modules (examples) | `effect` | `Arbitrary`, `ByteSize`, `ChannelSchema`, `Crypto`, `ErrorReporter`, `ExecutionPlan`, `FileSystem`, `Graph`, `HashRing`, `LayerMap`, `LayerRef`, `Newtype`, `PartitionedSemaphore`, `Path`, `PlatformError`, `Stdio`, `Terminal`, `TxChunk`, `Version` |

Consequence (inferred): pin `effect` and all `@effect/*` to an exact version. Steps 2 and 3 (sql, http-api) sit on unstable APIs that may break on 4.x minors.

## 2. Services and layers

Signature `[T] src/Context.ts`:
```ts
export interface Service<in out Identifier, in out Shape> extends Key<Identifier, Shape> {
  of(this: void, self: Shape): Shape
  context(self: Shape): Context<Identifier>
  use<A, E, R>(f: (service: Shape) => Effect<A, E, R>): Effect<A, E, R | Identifier>
  useSync<A>(f: (service: Shape) => A): Effect<A, never, Identifier>
}
// class form: Context.Service<Self, Shape>()("Id")
// make form:  Context.Service<Self>()("Id", { make: Effect | (...args)=>Effect })
```
Argument order: type parameters first, then the id (`[MIG] services.md`: v3 `Context.Tag(id)<Self, Shape>()` becomes `Context.Service<Self, Shape>()(id)`). Also `Context.Service<Shape>("Id")` for a function-style key.

**(a) Pure shape.** `[T] ai-docs/src/01_effect/03_services/01_service.ts`, abridged:
```ts
export class Database extends Context.Service<Database, {
  query(sql: string): Effect.Effect<Array<unknown>, DatabaseError>
}>()("myapp/db/Database") {
  static readonly layer = Layer.effect(Database, Effect.gen(function*() {
    const query = Effect.fn("Database.query")(function*(sql: string) { /* ... */ return [] })
    return Database.of({ query })
  }))
}
export type DatabaseService = Database["Service"]   // service-shape type
```
The id string convention in ai-docs is `"<package>/<path>/<Name>"`.

**(b) Effectful `make`** (`[MIG] services.md`):
```ts
class Logger extends Context.Service<Logger>()("Logger", {
  make: Effect.gen(function*() {
    const config = yield* Config
    return { log: (msg: string) => Effect.log(`[${config.prefix}] ${msg}`) }
  })
}) {
  static readonly layer = Layer.effect(this, this.make).pipe(Layer.provide(Config.layer))
}
```
- There is no auto `.Default` and no `dependencies` option. Wire dependencies with `Layer.provide`.
- Naming convention (`[MIG]`): `layer`, plus `layerTest`, `layerConfig`. `Default`/`Live` are no longer used.
- Type-level `make` detail `[T] Context.ts:327-334`: the `make` option is `Effect<Shape,E,R>` or `(...args) => Effect`.

**Accessing:** `const db = yield* Database` inside `Effect.gen`. `[MIG]` says "Prefer `yield*` over `use`". `Database.use((d) => d.query("x"))` returns `Effect<A,E,R|Database>`. Effect.Tag-style static accessors are removed.

**Composition** (`[T] ai-docs/.../20_layer-composition.ts`):
```ts
static readonly layerNoDeps: Layer.Layer<UserRepository, never, SqlClient.SqlClient> = Layer.effect(UserRepository, /* ... */)
static readonly layer = this.layerNoDeps.pipe(Layer.provide(SqlClientLayer))          // exposes only UserRepository
static readonly layerWithSqlClient = this.layerNoDeps.pipe(Layer.provideMerge(SqlClientLayer)) // exposes both
Layer.provide([UsersApiHandlers, SystemApiHandlers])   // Layer.provide also accepts an array
Layer.mergeAll(ApiRoutes, DocsRoute)                   // Layer.mergeAll(...layers) is variadic
```
- `Layer.scoped` is gone: `Layer.effect` now handles scoped acquisition (`[MIG v3-to-v4]`).
- `Layer.unwrap(Effect<Layer>)` exists, for layers that depend on config (`20_layer-unwrap.ts`).
- Defaults/config values: `Context.Reference<T>("id", { defaultValue: () => x })` (replaces `FiberRef`).
- Dynamic layer from Effect/Config: `Layer.unwrap(Effect.gen(...))`.

**Running at an entry point:**
- `Effect.runPromise(effect, options?)`, `Effect.runFork`, `Effect.runSync`, `Effect.runPromiseExit` exist `[T] Effect.ts`.
- `Runtime<R>` is removed. To run with services use `Effect.runForkWith(services)` / `runPromiseWith`, or `Layer.build`. (`[MIG runtime.md]`; `Layer.toRuntime` is gone.)
- `ManagedRuntime.make(layer, { memoMap? })` exists, with `.runPromise`, `.runSync`, `.runCallback`, `.dispose()` (`ai-docs/04_integration/10_managed-runtime.ts`):
```ts
export const appMemoMap = Layer.makeMemoMapUnsafe()
export const runtime = ManagedRuntime.make(TodoRepo.layer, { memoMap: appMemoMap })
await runtime.runPromise(TodoRepo.use((repo) => repo.getAll))
```
- Node/Bun processes: `NodeRuntime.runMain(Layer.launch(layer))` from `@effect/platform-node` (installs signal handlers).
- Workers: use `HttpRouter.toWebHandler` (see 7).

## 3. Schema v4 (`[T] src/Schema.ts`, `[MIG] schema.md`, `ai-docs/src/01_effect/02_schema`)

Naming: the base type is now `Schema.Constraint` (not `Top`/`Schema.Any`). Derive types with `typeof X["Type"]` and `typeof X["Encoded"]` (also `typeof X.Type`). `Schema.Schema.Type<>` helpers are gone.

```ts
// Class (ai-docs 10_schema-basics.ts)
export class User extends Schema.Class<User>("path/to/module/User")({
  id: Schema.Int, name: Schema.NonEmptyString, email: Schema.String,
  role: Schema.Literals(["admin", "member"])
}) {}
export type UserEncoded = typeof User["Encoded"]
// Struct
const S = Schema.Struct({ name: Schema.String, age: Schema.optionalKey(Schema.Number) })
// Tagged error (still Schema.TaggedError; optional 3rd arg = annotations, e.g. HTTP status)
export class UserNotFound extends Schema.TaggedError<UserNotFound>()("UserNotFound", { id: Schema.String }, { httpApiStatus: 404 }) {}
// Brand (pipeable, ONE literal id, type-only)
export const UserId = Schema.String.pipe(Schema.brand("UserId"))
export type UserId = typeof UserId.Type
// Literal / Literals / Union (array arg now)
Schema.Literal("a")   Schema.Literals(["a", "b"])   Schema.Union([A, B])   Schema.Null (not Literal(null))
```
- Optional fields `[T] Schema.ts:2395,2460`: `optionalKey(s)` gives `age?: number` (key may be absent, undefined not allowed). `optional(s)` gives `age?: number | undefined`. `Schema.requiredKey`/`required` reverse them.
- Option in TS, null on the wire: **`Schema.OptionFromNullOr(schema)`** still exists (null maps to None, None to null). Also `OptionFromUndefinedOr`, `OptionFromNullishOr`, `OptionFromOptionalKey` (missing key maps to None, new in v4), `OptionFromOptional`, `OptionFromOptionalNullOr`. `Schema.Option(a)` in v4 is the self schema (no wire transformation). v3 tagged-Option encoding is `Schema.toCodecJson(Schema.Option(v))`.
- Dates: `Schema.DateTimeUtc` = self schema (it expects a `DateTime.Utc` object). **`Schema.DateTimeUtcFromString`** is the ISO-string codec. Also `DateTimeUtcFromMillis`. `Schema.Date` = self schema (`Date` object); the string codec is `Schema.DateFromString`. Also `DateFromMillis`.
- UUID: `Schema.UUID` is removed. Use `Schema.String.check(Schema.isUUID())` (`isUUID(version?)`, `isULID()`).
- Number checks, applied as `Schema.Number.check(...)`: `Schema.Int` (= `Number.check(isInt())`), `isGreaterThan`, `isGreaterThanOrEqualTo`, `isLessThan`, `isLessThanOrEqualTo`, `isBetween({ minimum, maximum })`, `isMultipleOf(n)`, `isFinite`. `nonNegative`/`positive`/`negative`/`nonPositive`/`NonNegativeInt` are removed. For `NonNegativeInt` use `Schema.Number.check(Schema.isInt(), Schema.isGreaterThanOrEqualTo(0))` (`[MIG v3-to-v4]`). `Schema.Finite` exists.
- Strings: `NonEmptyString`, `Trimmed`, `isMinLength`/`isMaxLength`/`isPattern(re)`/`isNonEmpty()`.
- Collections: `Schema.Array(s)` (interface name `$Array`), `Schema.NonEmptyArray(s)`, `Schema.UniqueArray`, `Schema.Record(Schema.String, Value)` (two args now; was `{ key, value }`), `Schema.mutable`.
- pick/omit/partial (`[MIG schema.md]`; need `import { Struct } from "effect"`):
```ts
s.mapFields(Struct.pick(["a"]))   s.mapFields(Struct.omit(["b"]))
s.mapFields(Struct.map(Schema.optional))      // partial (allows undefined)
s.mapFields(Struct.map(Schema.optionalKey))   // exact partial
s.mapFields(Struct.assign(fieldsB))  // extend; or Schema.fieldsAssign(fieldsB)
```
- Parsers `[T] Schema.ts:1524..2307`. All take `(schema, parseOptions?)` and return a function `(input, parseOptions?)`:
  - `decodeUnknownEffect(s)`: `Effect<S["Type"], SchemaError, S["DecodingServices"]>`
  - `decodeEffect`, `encodeEffect`, `encodeUnknownEffect`
  - `decodeUnknownSync`, `decodeSync`, `encodeUnknownSync`, `encodeSync` (throw `SchemaError`)
  - `decodeUnknownExit`, `decodeUnknownResult`, `decodeUnknownOption`, `decodeUnknownPromise`, and `encode*` counterparts
  - `validate*` removed (use decode + `toType`)
- Parse error: **`Schema.SchemaError`** (a `Data.TaggedError("SchemaError")` with `.issue: SchemaIssue.Issue`; `Schema.isSchemaError`). `error.message` is the default-formatted text (`SchemaIssue.defaultFormatter`). Structured issues: `SchemaIssue.makeFormatterStandardSchemaV1()(error.issue).issues`. `ParseResult.*` is removed.
- Also: `Schema.toStandardSchemaV1(schema)`, `Schema.Defect()` (unknown cause field), `Schema.TaggedClass`, `Schema.TaggedStruct`, `.annotate(...)` (was `.annotations`), `Schema.decodeTo`, `SchemaGetter`, `SchemaTransformation`.

## 4. Errors

- `Schema.TaggedError<Self>()("Tag", fields, annotations?)` is the form used by **every** `ai-docs` example (service errors, HTTP errors, SQL). It is yieldable (`yield* new E({...})`) and is a schema, so it can sit in `HttpApiEndpoint` `error:` and be serialised.
- `Data.TaggedError("Tag")<{ ...props }>` also exists, unchanged `[T] Data.ts:1124`. It has no schema, so it is not usable in HttpApi endpoints or on the wire. It is used internally (`SchemaError`, `MigrationError`).
- Recommendation `inferred` from usage in `ai-docs`: `Schema.TaggedError` for domain/service/API errors, `Data.TaggedError` only for purely internal errors that never cross a schema boundary.
- Combinators (`[MIG error-handling.md]`): `Effect.fail`, `Effect.catchTag` (also accepts an array of tags: `Effect.catchTag(["A","B"], f)`), `Effect.catchTags({...})`, `Effect.mapError` unchanged. `Effect.catchAll` becomes **`Effect.catch`**. `catchAllCause` becomes `catchCause`. `catchSome` becomes `catchFilter`. New: `Effect.catchReason(tag, reason, onReason, onOthers)`, `Effect.catchReasons`, `Effect.unwrapReason`.
- Typed errors alongside a defect are no longer caught by any `catch*` (defects take precedence).
- `Effect.either` becomes `Effect.result` (returns `Result`, not `Either`).
- `Effect.fn` / `fnUntraced`:
```ts
export const f = Effect.fn("f")(
  function*(n: number): Effect.fn.Return<string, SomeError> {
    return yield* new SomeError({ message: "x" })   // always `return yield*` on failures
  },
  Effect.catch((e) => Effect.logError(`${e}`)),     // extra args are pipeline functions; "Do not use .pipe with Effect.fn"
  Effect.annotateLogs({ method: "f" })
)
export const g = Effect.fnUntraced(function*(size: number): Effect.fn.Return<number, SomeError> { ... })
```
`Effect.fn("name")` creates a span (the name should match the function name). `fnUntraced` is preferred for library code and hot paths. `Effect.fn("n")((x) => effect, Effect.mapError(...))` (non-generator form) is also used in ai-docs.

## Recommendation

1. Rewrite the conventions around `Context.Service` plus an explicit `static layer`/`layerTest`. Use `yield*` for access and `Schema.TaggedError` for domain/API errors. Use `Effect.fn("name")` for named service methods and `Effect.fnUntraced` for hot paths.
2. Take the Schema rules from section 3. Highlights: `Literals([..])`, `Union([..])`, `check(isX())`, `mapFields(Struct.*)`, `decodeUnknownEffect`, `SchemaError`.
3. Mark `effect/http`, `effect/http-api`, `effect/sql`, `effect/schema` (`Model`) and `@effect/{vitest,sql-d1}` as unstable in the rule file. Pin exact versions.
4. Treat `ai-docs` in the `effect` tarball (`node_modules/effect/ai-docs/`) as the preferred reference for agents. It is shipped with every install and matches the installed version. `inferred`: the CLAUDE.md/AGENTS.md in the package point at it.
