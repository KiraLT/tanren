Neither command was long-running (the biome probe took 1.6 ms); the briefs forbade `rm -r*` in text, which did not stop a cleanup sub-command.
2. **Team-lead dispatches were foreground.** All five team-leads passed `run_in_background: "true"` as a JSON string. Across the night, 57/57 string-valued Agent calls acked only with the child's final report (foreground); 27 boolean-`true` calls acked "Async agent launched" within seconds. So catalog's turn (`ae851b92496418e6c`) blocked at 00:50:11 on C5 until 09:17:30 and illustrations' (`a695af1edbf38b2a3`) at 00:52:44 on I1 until 09:18:39; a foreground Agent call has no timeout, so team-lead.md step 5's wait loop never ran. ## Proposals for the Lead (exact text)
P1 `.claude/skills/lead-playbook/SKILL.md` "Unattended mode", append bullets:
```
- Never end a turn while any agent is live. Before waiting, start one background
  watchdog: `T=<tasks dir>; while :; do for f in $T/a*.output; do grep -q
  SubagentHandback $f && continue; [ $(( $(date +%s) - $(stat -f %m $f) )) -gt 900 ]
  && echo "SILENT $(basename $f) $(tail -c 300 $f)"; done; sleep 60; done` with
  `run_in_background: true` and a `timeout` of the remaining window; its first
  SILENT line wakes you (v2 night: two children silent 8 h, Lead asleep 7 h 48 m).
- A silent agent's last tool call is read from `tail -c 2000 tasks/<id>.output`.
  A permission prompt (ask-list sub-command) cannot be answered by you: mark the
  task stalled, re-dispatch it with the fix, and log the command in incidents.md.
- Unattended = ask rules become deny rules: before leaving, copy every
  `permissions.ask` entry into `permissions.deny` in `.claude/settings.local.json`
  (a denied command returns an error to the agent at once; an asked one blocks
  forever) and remove them when the owner is back.
```
